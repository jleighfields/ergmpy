# tasks

Plans for non-trivial work, one file per plan, named
`<description>-<YYYY>-<MM>-<DD>.md`. Check a plan in with the user before
implementing it, mark items complete as the work proceeds, and add a review
section when it is finished. Finished plans move to `completed/`.

`CLAUDE.md`'s **Plans and lessons** section is the authority on when a plan is
required. Corrections that change how work is done go in `docs/lessons.md`
instead — a lesson outlives the plan that produced it.
